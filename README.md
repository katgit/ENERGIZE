# NSF NRT ENERGIZE


## Structure

- **Part1/** - Beginner session. Covers Python fundamentals.
- **Part2/** - Advanced session. Run on the **Shared Computing Cluster (SCC)**, with access to GPU nodes. Covers advanced data structures/dictionaries, NumPy/Pandas at a deeper level, CPU vs. GPU computing, SCC job submission, virtual environments, and Jupyter on the SCC.
