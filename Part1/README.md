# Part 1 - Beginner Session (Local Computer)

Run these notebooks on your own laptop using Jupyter (or VS Code with the Jupyter extension).

Before the workshop, see **[00_Setup_Python_Jupyter_VSCode.md](00_Setup_Python_Jupyter_VSCode.md)** for step-by-step installation directions (Mac and Windows).

## Notebooks, in order

1. **01_Python_Basics_and_Data_Structures.ipynb** - variables, strings, lists, list comprehensions, dictionaries, tuples, loops, `if`/`elif`/`else`.
2. **02_Functions.ipynb** - defining functions, parameters, return values, docstrings, default arguments.
3. **03_Modules_and_NumPy_Intro.ipynb** - the `math` module, introduction to NumPy arrays, vectorized math, boolean indexing.
4. **04_Scripts_and_Command_Line_Arguments.ipynb** - `if __name__ == "__main__":`, `sys.argv`, writing a runnable `.py` script.
5. **05_Plotting_with_Matplotlib.ipynb** - basic line/scatter plots, labels, titles, plotting NumPy data.
6. **06_Data_Analysis_with_Pandas.ipynb** - loading CSV data, exploring, selecting, filtering, grouping, and sorting with pandas.
7. **07_From_Script_to_the_SCC.ipynb** - converting notebook code into a batch-ready script, and the basics of logging into the SCC and submitting a job with `qsub`.

## Data

`tensile_test_data.csv` - a small sample tensile-test dataset used throughout, especially in notebook 6.
